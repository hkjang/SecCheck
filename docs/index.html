Rule Engine 자동 배정과 암호학적 해시 체인 감사로그로 완벽한 추적성을 제공합니다.

SecCheck의 핵심 기능 둘러보기

대시보드부터 Rule Engine, 체크리스트 작성, 증적 암호화, 검토 대기열, 시스템 설정까지 전 화면을 확인하세요.

보안 심의 현황 대시보드

진행 중 심의, 신규 검토 대기/미처리 보완 요청, 14일 내 오픈 예정, 심의 완료 통계를 실시간으로 확인하고 4단계 Snapshot 프로세스를 안내합니다.

  • ✓ 실시간 KPI 메트릭 및 최근 심의 요약 테이블
  • ✓ 심의 요청자와 보안 담당자별 맞춤형 화면 제공
  • ✓ Snapshot 기반 단계별 업무 흐름 직관적 안내

Rule Engine 기반 신규 심의 요청

서비스 기본정보와 9가지 적용 조건을 입력하면 Rule Engine이 조건에 부합하는 게시 템플릿의 항목들을 불변 스냅샷으로 자동 배정합니다.

  • ✓ 개인정보/신용정보, 클라우드, Docker, K8s, 외부 연계 조건 평가
  • ✓ 게시 후 불변인 체크리스트 버전과 제출 시점 Snapshot 생성
  • ✓ 필요 시 관리자의 수동 배정 조정(Rule Override) 감사 추적

체크리스트 작업 공간 & 실시간 진행 집계

진행률(%)과 적합/조건부/미흡/N/A 검토 집계를 상단에 표시하며, 템플릿/섹션별 빠른 이동 및 1클릭 다중 포맷(Excel, PDF, ZIP) 내보내기를 지원합니다.

  • ✓ 작성 진행률 및 검토 결과 실시간 집계 바
  • ✓ 미작성, N/A, 증적 누락, 보완 요청 항목 즉시 필터링
  • ✓ Excel(.xlsx), PDF(.pdf), ZIP 결과물 1클릭 다운로드

항목 편집 & 증적 파일 암호화 업로드

적용 여부(Y/N/N/A), 자체 판단, N/A 필수 사유를 입력하며 백그라운드 자동 저장이 동작합니다. 증적은 Magic MIME 검증 후 AES-256-GCM으로 암호화 저장됩니다.

  • ✓ 타이핑 1.2초 후 무중단 백그라운드 자동 저장
  • ✓ 증적 파일 Magic MIME 검증, SHA-256 해시, AES-256-GCM 암호화
  • ✓ N/A 사유 및 필수 증적 누락 시 서버 제출 검증 결함 차단

통합 Security Controls & 영향 범위 추적

표준 보안 통제 코드(SEC-ENC-001 등)를 단일 카탈로그로 관리하고, 해당 통제가 연결된 체크리스트 템플릿 및 적용된 심의의 영향 범위(Blast Radius)를 추적합니다.

  • ✓ 전사 표준 Security Control 통합 관리
  • ✓ Control 수정/변경 시 영향 받는 심의 건수 실시간 파악
  • ✓ ISMS-P, ISO 27001 등 규제 통제 항목과의 매핑

Excel 가져오기 마법사 & 템플릿 버전 관리

기존에 엑셀로 관리하던 보안 점검표를 업로드하고 컬럼 매핑을 통해 손쉽게 신규 템플릿으로 변환합니다. 게시된 버전은 불변으로 보호됩니다.

  • ✓ 기존 엑셀 시트 업로드 및 지능형 컬럼 매핑
  • ✓ 개발보안, 개인정보, 클라우드, K8s 기본 템플릿 내장
  • ✓ 버전 복제 및 변경 관리 후 안전한 새 버전 게시

SHA-256 해시 체인 불변 감사로그

모든 심의 행위, 승인 결정, 설정 변경, 키 회전 이력이 이전 이벤트 해시와 결합된 블록체인형 해시 체인으로 기록되며 원클릭으로 무결성을 검증합니다.

  • ✓ 수정·삭제 API가 없는 추가 전용(Append-only) 감사 추적
  • ✓ SHA-256 해시 체인 링크 및 원클릭 전수 무결성 검증
  • ✓ Keycloak OIDC SSO, SMTP 알림 큐, ClamAV 안티바이러스 설정
Architecture

엔터프라이즈 오프라인 운영을 위한 3대 아키텍처

외부 통신 없이 단일 Docker 컨테이너와 PostgreSQL만으로 영구 지속되는 안정성을 보장합니다.

🏛️

3계층 불변 스냅샷 분리

템플릿, 게시 버전, 심의 배정 스냅샷을 엄격히 분리하여 템플릿이 추후 변경되더라도 기존 심의의 원본 데이터와 증적이 100% 영구 보존됩니다.

🔐

AES-256-GCM 증적 봉투 암호화

사용자별 개인 데이터 키로 증적을 암호화하여 저장하며, 무중단 키 회전(Zero-Downtime Key Rotation)을 통해 이전 증적의 안전한 복호화를 유지합니다.

⛓️

SHA-256 해시 체인 감사로그

이전 이벤트 해시를 연결하는 암호학적 해시 체인을 구축하여 DB 직접 조작이나 위변조 시도를 원천 차단하고 상시 무결성을 검증합니다.

Quick Start

4개 환경변수로 30초 만에 시작하기

오프라인 환경에서도 단 한 줄의 명령어로 즉시 기동할 수 있습니다.

Docker 컨테이너 1줄 실행 가이드
docker run -d --name seccheck --restart unless-stopped \ -p 8080:8080 \ -e POSTGRES_DSN='postgres://seccheck:password@postgres.internal:5432/seccheck?sslmode=require' \ -e BOOTSTRAP_ADMIN='admin' \ -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \ -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \ seccheck:v0.1.0
