SecCheck
Excel 보안 심의를 넘어 추적 가능한 Security Control로.
docker run -d --name seccheck -p 8080:8080 \
  -e POSTGRES_DSN='postgres://seccheck:pass@postgres:5432/seccheck' \
  -e BOOTSTRAP_ADMIN='admin' \
  -e BOOTSTRAP_ADMIN_PASSWORD='password1234' \
  -e ENCRYPTION_KEY='01234567890123456789012345678901' \
  seccheck:v0.1.0
